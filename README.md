# SupermarketSalesAPI

A simple ASP.NET Core REST API for managing supermarket sales data.

## Features
- Manage products, categories, branches, and sales
- CRUD endpoints with validation
- Entity Framework Core + SQL Server integration

## Tech Stack
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- FluentValidation

## Project Structure
- `Controllers` — API endpoints
- `Models` — domain models
- `DTOs` — request/response models
- `Services` — business logi
- `Repositories` — data access
- `Data` — EF Core database context
- `Validations` — DTO validation rules
